# Student Attendance Management System

## 📌 Overview

A C++ and Data Structures & Algorithms based system for
managing student attendance efficiently.

## ✨ Features

- Add student records
- Manage attendance
- Search students
- Sort student records
- Attendance tracking
- File-based data storage

## 🧠 Data Structures & Algorithms

- Linked List
- Stack
- Queue
- Searching
- Sorting
- File Handling

## 🛠️ Technologies

- C++
- C++17
- Data Structures & Algorithms
- File Handling
